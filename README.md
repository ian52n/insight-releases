# Insight — Releases

Public release channel for **Insight**, the macOS meeting-insight app by AI Editor LLC.

- **Download the latest version:** [Insight.dmg](https://github.com/ian52n/insight-releases/releases/latest/download/Insight.dmg)
- **Website:** https://ai-editor.app/insight
- **Requirements:** macOS 14+, Apple Silicon. Signed & notarized.

`appcast.xml` in this repo is the [Sparkle](https://sparkle-project.org) update feed the app checks for automatic updates. Release binaries live under [Releases](https://github.com/ian52n/insight-releases/releases).
